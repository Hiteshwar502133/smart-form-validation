# 🧠 Smart 3D Form Validator

A modern and interactive frontend form built using HTML, CSS, and JavaScript with real-time validation, dynamic UI feedback, and 3D background effects using Three.js.

## 🚀 Features

- ✨ Glassmorphism UI design  
- 🧾 Floating input labels  
- 🔐 Real-time form validation  
- 📊 Password strength indicator (Weak / Medium / Strong)  
- ✔️ Email validation with live tick feedback  
- 🌗 Dark / Light mode toggle  
- 🎬 Smooth animations  
- 🌌 3D animated background using Three.js  

---
